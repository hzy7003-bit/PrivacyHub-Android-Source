# Contributing and feedback

This repository is published for transparency, privacy review, and security audit. External code contributions and pull requests are not currently accepted.

The following feedback is welcome:

- Issues and bug reports
- Security reports (see [SECURITY.md](SECURITY.md))
- Audit feedback
- Documentation issue reports

Do not include vault contents, passwords, private keys, activation codes, device identifiers, or other private data in public reports.

If the project later begins accepting code contributions, it will publish a separate contribution policy before doing so.
