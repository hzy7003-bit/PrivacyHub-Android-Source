# Security reports

This snapshot is published for independent privacy and security review. Security reports are welcome.

If GitHub's private vulnerability reporting is available for this repository, use that private channel. Otherwise, open an Issue asking for a private reporting route and do not include exploit details, credentials, personal data, activation codes, device identifiers, or vault contents in the public Issue.

Please include the affected snapshot version, Android/API level, and a concise description that avoids sensitive data. Do not test against other people's devices, accounts, or data.

The public source snapshot and its Debug builds are not official signed releases. Reported issues may require reproduction on supported Android versions before a fix or release decision is made.
